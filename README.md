# CodeAlpha - Car Price Prediction Using Machine Learning

## Project Overview

This project develops a machine learning model to predict the selling price of used cars based on various vehicle characteristics. The workflow includes data preprocessing, feature engineering, exploratory data analysis, model comparison, hyperparameter tuning, and performance evaluation.

## Objective

To build an accurate regression model capable of estimating car selling prices using historical vehicle data.

## Dataset Features

* Car Name
* Year
* Present Price
* Driven Kilometers
* Fuel Type
* Selling Type
* Transmission
* Owner

### Target Variable

* Selling Price

* Matplotlib

* Jupyter Notebook

1. Data Collection

8. Hyperparameter Tuning
9. Model Evaluation

## Models Used

* Linear Regression
* Ridge Regression
* Lasso Regression
* Decision Tree Regressor
* Random Forest Regressor
* Gradient Boosting Regressor
* Extra Trees Regressor

## Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

## Key Features

* Multiple model comparison
* Cross-validation
* Hyperparameter tuning using GridSearchCV
* Feature engineering

## Real-World Applications

* Used Car Marketplaces
* Vehicle Dealerships

* Loan and Financing Services

## Results

The project identifies the best-performing regression model and predicts car selling prices with high accuracy.
